# 📝 NOTES_HUB - Centralized Student Resource

NOTES_HUB is a web-based repository designed to solve the problem of fragmented study materials for Computer Science students.

### 🛠 Platform Structure
* **Categorization:** Logical folder structure for different subjects like **Computer Networking, RDBMS, and Discrete Maths**.
* **Accessibility:** A simplified UI that allows students to view or download PDFs and hand-written notes instantly.
* **Tech Stack:** HTML5 for structure and CSS3 for a clean, student-friendly interface.
